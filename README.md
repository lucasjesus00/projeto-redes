# Projeto Redes Sociais

Projeto front-end que simula a visualização de páginas de redes sociais dentro de uma moldura de smartphone. Uma página inicial reúne atalhos para as telas de Home, YouTube, GitHub, Instagram, X e Facebook, que são carregadas em um `iframe`. O objetivo é praticar a criação de páginas HTML e estilos CSS e a navegação entre conteúdos locais.

## Tecnologias utilizadas

- **HTML5** — páginas e estrutura de navegação.
- **CSS3** — apresentação da moldura, telas e elementos visuais.
- **Frameworks e bibliotecas:** não utilizados.

## Como executar localmente

Não há dependências para instalar. É necessário apenas um navegador moderno.

1. Clone o repositório:

   ```bash
   git clone https://github.com/lucasjesus00/projeto-redes.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd projeto-redes
   ```

3. Inicie um servidor local na raiz do projeto:

   ```bash
   python -m http.server 8000
   ```

4. Acesse [http://localhost:8000](http://localhost:8000) e use os ícones para navegar entre as telas.

Também é possível abrir `index.html` diretamente no navegador. O servidor local é recomendado para evitar limitações de carregamento de recursos locais.
